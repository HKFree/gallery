# Timeline documentation

The timeline shows gallery photos grouped by month, newest first, and lets you scroll back
into the past. It exists in two scopes: inside each AP gallery, and across the whole network.

![An AP gallery in timeline view](images/ap-timeline.png)

This documentation follows the [Diátaxis](https://diataxis.fr) framework. Pick the part that
matches what you need right now:

| | When you want to… | Read |
| --- | --- | --- |
| **Tutorial** | learn the timeline by using it, step by step | [Exploring the timeline](tutorial.md) |
| **How-to guides** | get a specific task done | [How-to guides](how-to.md) |
| **Reference** | look up URLs, parameters, rules and commands | [Reference](reference.md) |
| **Explanation** | understand why it works the way it does | [Explanation](explanation.md) |

The UI is in Czech. These pages quote its labels as they appear on screen, for example
**Časová osa** (Timeline), **Mřížka** (Grid), **Starší** (Older) and **Novější** (Newer).
